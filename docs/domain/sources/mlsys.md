# mlsys — AI/ML research engineering + ML systems: source catalogue

Compiled 2026-11-01 for the domain-REAP track (`docs/domain/PLAN.md`: D0 corpora → D1 saliency → D2 masks → fine-tune → eval).
Everything below comes from **live queries run 2026-11-01** (search log at the end), not recall.
Licences were checked on 2026-11-01 against the HF API `cardData.license` and the repo LICENSE file (`gh api repos/X/license`).
Dates are `created / last-updated`: HF `createdAt` / `lastModified`, GitHub `created_at` / `pushed_at`.
Nothing was downloaded beyond `datasets-server` first-rows samples. **[UNVERIFIED]** marks every claim not checked against a primary source.
Every scheduled source is tagged `generator:` so a build can drop it (PLAN.md).

Thor constraints apply to every row: Linux aarch64, sm_110 (tcgen05 yes; FlashMLA has no sm_110 build), unified memory, and no co-running beside a vLLM server.
